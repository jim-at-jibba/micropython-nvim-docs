## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## This site

- Docs for micropython.nvim v3 only. The plugin lives at
  https://github.com/jim-at-jibba/micropython.nvim (checked out at `../micropython.nvim`).
- Use the domain vocabulary in the plugin's `CONTEXT.md` (Device, Port, Upload, Mount, Run,
  Soft reset, Hard reset, Stubs...).
- Pages live in `src/content/docs/<section>/`; each section folder is autogenerated into the
  sidebar.
- Internal links are absolute and include the base: `/micropython-nvim-docs/<page>/`.
  `npm run build` validates them.
